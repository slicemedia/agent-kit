# Inspection output

Report:

1. Scope: exact site/page identifiers, environment, branch, locale, viewport, and evidence source.
2. Instructions: site Agent Instructions read and any unresolved references.
3. Structure: page elements, component definitions, instances, props, variants, shared styles, bindings, and CMS boundaries.
4. Behavior: native interactions, custom code, applied versus registered scripts, events, and mutation sources.
5. Contract: stable attributes, explicit identifiers, and configurable values.
6. Risks: shared-resource blast radius, stale scripts, accessibility, performance, mode, bridge, permissions, or publication state.
7. Recommendation: smallest reversible change, required confirmation, and verification plan.

Redact identifiers that are not necessary to act on the finding.
