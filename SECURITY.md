# Security

## Supported versions

Security fixes are applied to the current `latest` minor line and the active release candidate on
the `next` tag during the `0.x` series. Older minor releases and candidates superseded on `next` are
not maintained as separate support lines. Supported Node versions are documented in `README.md`
and `package.json`.

Maintenance and vulnerability handling are best-effort. Slice Media does not provide a guaranteed
response time, remediation deadline, support SLA, or long-term support branch for this project.

## Reporting a vulnerability

Report suspected vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/slicemedia/agent-kit/security/advisories/new).
Do not include access tokens, site identifiers, client content, personal data, or other secrets in
a public issue. Include the affected version, impact, reproduction steps, and a minimal sanitized
proof of concept when possible.

Use a public GitHub Issue for ordinary defects that do not create a security or privacy risk.
